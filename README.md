# Pysano Updates

Public distribution feed for [Pysano](https://github.com/kairon27/Pysano).

This repository contains only:

- the Sparkle `appcast.xml` feed;
- signed Stable and Beta release archives attached to GitHub Releases;
- public release notes.

Source code remains in the private Pysano repository. API keys, local models,
code-signing identities, and the private Sparkle EdDSA key are never stored here.
